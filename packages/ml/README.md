# @tradejs/ml

Internal ML runtime assets for the TradeJS TypeScript framework.

This package is private and is not intended as a public authoring/runtime dependency.

## What It Contains

- Python training helpers
- model/runtime container assets
- internal ML build glue used by the repository

## External Users

Use the documented ML flow through:

- `@tradejs/cli`
- `@tradejs/node`
- docs at https://docs.tradejs.dev/ai-ml

Do not import `@tradejs/ml` directly in project code.
