# Стандарт сравнительных графиков исследования

Главный сравнительный график любого core-, AI-gate-, candidate- или
revalidation-исследования строится в одном формате. Вспомогательные scatter,
распределения и карточки сделок допустимы дополнительно, но не заменяют его.

## Обязательная форма

Один SVG/PNG содержит общий UTC-масштаб времени и три панели:

1. накопленный net PnL после комиссий и проскальзывания;
2. просадку от максимума того же net PnL;
3. последовательные убыточные завершённые сделки. Если сохранены только
   точки equity, подпиши панель как последовательные отрицательные шаги equity.

Легенда обязана явно писать роль каждой линии: `BASELINE`, `CANDIDATE`,
`REFERENCE` или `DIAGNOSTIC`, затем понятное название, `N` и итоговый PnL с
единицей. Ровно одна линия имеет роль `BASELINE`. Подгруппы baseline или
кандидата не называются кандидатами. Если новых кандидатов нет, напиши это в
заголовке или подзаголовке и используй роли `REFERENCE`/`DIAGNOSTIC` для
остальных линий.

Указывай режим AI-gate в подписи каждой линии легенды. Для ядра без
дополнительных правил допуска пиши «чистый core · без AI-gate». Если у
варианта есть отдельное детерминированное правило допуска, укажи его название
и «без AI-gate». Для линии с AI-gate пиши «с AI-gate» и указывай версию или
название gate, если сравниваются несколько. Режим проверяй по сохранённой
конфигурации каждого прогона.

Все линии используют одинаковые окно, universe, интервал, расходы, исполнение
и нормализованный риск. Не смешивай raw core и gated composition на одном
финальном сравнении. Выделение заливкой обозначает заранее определённый новый
или holdout-период, а не выбранный после просмотра результата участок.

Перед построением прочитай
[`production-baseline.md`](production-baseline.md). Если стратегия есть в
`production`, ровно одна линия `BASELINE` обязана представлять её точную
текущую развёрнутую композицию. Старый research-control, stable-пакет или
кандидат из предыдущего исследования не может называться production baseline.
После подтверждённого развёртывания кандидата новый график показывает его как
`BASELINE`, а прежний baseline как `REFERENCE` или историческую линию. `N`
всегда относится к общему окну самого графика и не переносится из deployment
или старого исследования.

## Общий рендерер

Подготовь Project-owned JSON по схеме
`tradejs-research-comparison-chart/v1`:

```json
{
  "schema": "tradejs-research-comparison-chart/v1",
  "title": "Strategy 15m · сравнение AI-gates",
  "subtitle": "Одинаковое окно, риск и расходы",
  "universeLabel": "530 USDT-контрактов Bybit",
  "pnlUnit": "USDT",
  "window": {
    "start": 1698019200000,
    "end": 1794240000000,
    "highlightStart": 1792713600000
  },
  "series": [
    {
      "id": "current-gate",
      "label": "с AI-gate · действующий",
      "role": "baseline",
      "trades": [[1698253200000, 11.24]],
      "metrics": { "trades": 1, "pnl": 11.24 }
    },
    {
      "id": "candidate-gate",
      "label": "с AI-gate · переобученный",
      "role": "candidate",
      "trades": [[1698253200000, 9.8]],
      "metrics": { "trades": 1, "pnl": 9.8 }
    }
  ]
}
```

`trades` содержит завершённые сделки как `[exitTimestamp, netPnl]`. Рендерер
сам вычисляет equity, realized drawdown и loss streak. Для компактно сохранённой
истории можно передать `equity: [[timestamp, cumulativePnl]]` и обязательные
`metrics`; тогда панель streak отражает отрицательные шаги сохранённой equity,
что фиксируется в summary. Для подтверждённо пустого ряда передай пустую
`equity` с `equityStatus: "verified-empty"`, `N=0` и `PnL=0`; для ряда без
доступной кривой используй `equityStatus: "unavailable"`. Рендерер явно
пометит такие линии и не выдаст отсутствие наблюдений за нулевую equity.

Из `tradejs-project` запусти:

```bash
yarn node "$TRADEJS_FRAMEWORK_REPOSITORY_ROOT/.codex/skills/strategy-backtest-research/scripts/research-comparison-chart.mjs" \
  --spec data/research/<lineage>/comparison-chart.json \
  --out data/research/<lineage>/comparison-chart
```

Команда создаёт `.svg`, `.png` и `.summary.json`, не перезаписывает существующие
файлы и сохраняет контрольные суммы. SVG каноничен, PNG предназначен для чата.
Визуальное сокращение сохраняет локальные минимумы/максимумы каждой панели и не
меняет полные метрики.

## Доказательность и хранение

- Строй график только из reconciled completed-trade данных или из ранее
  сохранённой checksum-bound equity.
- Если trade-level данные уже удалены по retention и equity не сохранена, не
  восстанавливай кривую из агрегатов и не повторяй завершённое исследование
  только ради картинки. Покажи сохранённый график или укажи ограничение.
- Сохрани spec, summary, SVG и PNG до очистки временных строк сделок. В заметке
  зафиксируй их SHA-256 и роли линий.
- Прямые сегменты соединяют завершённые наблюдения только для представления;
  это не внутрисделочная mark-to-market equity и не сглаживание.
