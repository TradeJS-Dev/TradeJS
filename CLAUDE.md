## Shared TradeJS skills

Read the matching complete `.codex/skills/<name>/SKILL.md` before using a
TradeJS workflow. `$tradejs-mcp` routes remote market/runtime inspection through
the authenticated MCP server. Skill files remain canonical in `.codex/skills`;
do not create a second editable copy under `.claude/skills`.
OAuth login and consent are performed by the human user.
