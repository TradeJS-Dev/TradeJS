# Правила интерфейса

## Семантика и фокус

Для действия используй кнопку, для перехода — ссылку с корректным `href`,
сохраняя Cmd/Ctrl+click и открытие в новой вкладке. Переиспользуй доступные
компоненты UI: новый click-handler на `div` не заменяет клавиатурный контракт.
Не добавляй нативной кнопке дублирующую обработку Enter без причины.

Кнопке-иконке нужно доступное имя, полю — связанный label, содержательной
картинке — alt, декоративной — исключение из accessibility tree. Placeholder
не заменяет название поля. Сообщения об асинхронном результате должны быть
доступны вспомогательным технологиям без навязчивого повтора.

Проверь Tab/Shift+Tab, видимый фокус, возврат после закрытия диалога и
перекрытие липкими панелями. Сохраняй заголовки и возможность масштабирования.
У drag/swipe должна быть применимая обычная/клавиатурная альтернатива.

## Формы и состояния

Сохраняй валидацию, pending, защиту от повторного submit, disabled и обработку
несохранённых данных по контракту. Учитывай `name/type/autocomplete` по
назначению, разрешай вставку. Ошибка связана с полем и видна после неудачной
отправки; фокус переводится только по ожидаемому поведению.

Проверь применимые пустое состояние, загрузку, отказ, повтор и успех.
Ошибка сохранения не должна закрыть редактор как при успехе. Не добавляй
подтверждения или новый workflow без требований. Для опасного действия
проверяй защиту на контролируемой границе, не реальным действием в runtime.

## Контент и геометрия

Проверь длинные имена стратегии/тикеров, числа, пустые значения и большие
списки, если они затронуты. На узком экране и при масштабе должны оставаться
доступны действия. Перенос, `min-width: 0` и truncation выбирай по смыслу:
обязательный полный текст нельзя просто спрятать многоточием.

График с canvas не заменяет доступное имя и текст существенного состояния.
Резервируй размер изображения/графика, если это предотвращает скачок разметки.
Не загружай критичное изображение первого экрана лениво по общему рецепту.
Учитывай `prefers-reduced-motion`, возможность прервать анимацию и значение
цвета: он не должен быть единственным признаком ошибки или направления.

Даты, числовую точность и формат значений бери из существующих утилит и
компонентов. Не вводи ICU, новый i18n-пакет, Title Case или единый формат
денег по чужому руководству. Сохраняй различие нуля и отсутствующих данных.

## Навигация и стоимость

Сохраняй reload/back, URL и query-параметры по контракту страницы. Не
синхронизируй любое состояние с URL и не вводи словарь `ROUTES`, которого
нет в выбранном пакете. Для тяжёлого списка/ввода сначала измерь стоимость,
найди существующую виртуализацию и проверь клавиатуру, поиск и фокус.

Чтение CSS или отсутствие скролла не доказывает отсутствие clipping.
Проверь реальные границы дочерних и родительских элементов. Новые CSS
возможности, touch и safe areas проверяй на целевом браузере/устройстве по
риску. Не заявляй проверку всех браузеров после одного Chromium-прогона.
